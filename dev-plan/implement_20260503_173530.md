## 2. Architecture Decisions

| 결정 | 선택 | 근거 |
|---|---|---|
| LICENSE 위치 | 저장소 루트 (`/LICENSE`) | GitHub 표준; `pyproject.toml`의 `license = { text = "MIT" }`와 일관 |
| `scripts/` sdist 포함 | `MANIFEST.in` + `pyproject.toml`의 `tool.setuptools.exclude-package-data` 검토 | scripts/는 패키지 외부이므로 MANIFEST.in으로 sdist에만 포함 (wheel에는 불필요) |
| 휠 빌드 도구 | `python -m build` (PEP 517 표준) | `setup.py` 의존 회피, 표준 도구만 사용 |
| 빌드 산출물 검증 | tmp venv에서 `pip install dist/*.whl` + `claude-skill-factory --version` smoke | 실 사용자 흐름 모사 |
| 첫 commit 범위 | 전체 워킹트리 1회 commit (squash 효과) | dev plan은 archival, history 노이즈 회피 |
| 커밋 메시지 | Conventional Commit (`feat:` prefix) + 변경 사항 7행 | 향후 changelog 자동화 호환 |
| Git push | **수행하지 않음** | 사용자 명시 요청 시에만 (AGENTS §10) |

## 6. Risks

| 위험 | 영향 | 완화 |
|---|---|---|
| `python -m build` deps 부재 | 중간 | `pip install build` 자동 install 단계 포함 |
| MANIFEST.in glob 누락 → scripts 빠짐 | 낮음 | TC-2.1로 검증 |
| pyproject.toml license 변경 시 build error | 낮음 | 일단 그대로 두고 파일만 추가 (안전) |
| 첫 commit에 `.venv` 100MB+ 포함 | 높음 | `.gitignore` 사전 점검 + `git status` 검토 |
| pre-commit hook 차단 | 낮음 | 현재 hook 없음 확인됨 |
| commit 후 IDE diagnostics 잔존 | 낮음 | 무관 (IDE는 시스템 Python 3.14 사용) |
